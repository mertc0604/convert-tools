# Security policy

Güvenlik açığı bildirimleri public issue yerine GitHub deposundaki
**Security → Report a vulnerability** kanalıyla gönderilmelidir.

Bildirimde etkilenen sürüm, yeniden üretim adımları, beklenen etki ve mümkünse
en küçük örnek girdi bulunmalıdır. Hassas veri, gerçek operasyon koordinatı,
erişim anahtarı veya kimlik bilgisi eklenmemelidir.

Desteklenen sürüm mevcut `main` dalı ve son yayımlanan sürümdür.
